# Ashmit Mukherjee

I'm a Computer Science senior at NYU Abu Dhabi, with a minor in Economics. I'm interested in computational social science: how people make decisions together, and what changes when AI participates.

My current work spans software for human–AI cooperation experiments and training and evaluation of protein language models. I also work on a capstone about detecting faults in experimental software using synthetic decisions.

[Research and contributions](https://ashmitmukherjee.com/#research) · [Projects](https://ashmitmukherjee.com/work/) · [LinkedIn](https://www.linkedin.com/in/ashmit-mukherjee/)

## Public projects

- [CAMP](https://github.com/Ansester/camp-final-project): a five-person campus equipment project. My contributions cover staff APIs, backend testing, and client API utilities.
- [Hinglish NER](https://github.com/Ansester/hinglish-ner-research): a four-person NLP course project, with preprocessing, training, and evaluation code for multilingual token classifiers.
- [Salary regression](https://github.com/Ansester/salary-prediction-ml): historical job-listing data, grouped evaluation, and a Streamlit demonstration.
- [Community crime data analysis](https://github.com/Ansester/crime-prediction-ml): an observational regression exercise on historical U.S. community data.
- [eCampusExplorer](https://github.com/Ansester/eCampusExplorer): Unity campus-tour navigation scripts, with the supplied controller's original credit preserved.

Earlier C++ coursework covers [sparse matrices](https://github.com/Ansester/Matrix-Computation-System), [hash tables](https://github.com/Ansester/Dictionary-Management-System), [heat diffusion](https://github.com/Ansester/Thermal-Distribution-Simulation), [least-squares fitting](https://github.com/Ansester/SeawaterFreezingTempCalc), and an [iterated Prisoner's Dilemma](https://github.com/Ansester/Game-Theory-Simulation).

The faculty research repositories are private. My [website](https://ashmitmukherjee.com) explains the questions, my role, and the current evidence separately from these public coursework repositories.
